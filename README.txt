ГРАНЬ v14 — Cinematic Remote 3D

Модели и HDRI НЕ находятся внутри проекта.
При запуске браузер обращается к Poly Haven API и скачивает:
- wooden_table_02
- industrial_storage_cart
- utility_box_01
- workshop HDRI

Three.js + GLTFLoader + RGBELoader загружаются из CDN.
Нужен интернет и браузер с WebGL.

Сцена:
1) workshop
2) laser cutting
3) assembly
4) architecture/window reveal

Важно: браузер может блокировать внешний ресурс, если CDN/asset server недоступен или изменит CORS.
