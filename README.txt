RY-L1390 TRUE 3D / THREE.JS PACK

1. Распакуй папку.
2. Запусти run.py через Python.
3. Откроется http://127.0.0.1:8000/index.html
4. Для телефона: компьютер и телефон должны быть в одной Wi‑Fi сети; в run.py замени 127.0.0.1 на IP компьютера и открой http://IP:8000/ на телефоне.

Внутри:
- index.html — Three.js viewer
- run.py — локальный сервер
- assets/ — 20 отдельных GLB-компонентов
- RY-L1390_ASSEMBLED.glb — собранная контрольная модель

Модели являются настоящей 3D-геометрией и подготовлены как независимые объекты для последующей GSAP/Three.js анимации.
