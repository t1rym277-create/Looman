ГРАНЬ — Cinematic 3D optimized build

Запуск:
1. Распакуйте архив.
2. Откройте index.html.

Внутри проекта локальные GLB-модели и текстуры. Сайт не требует загрузки 3D-моделей с внешних CDN.

Оптимизация:
- компактные GLB;
- WebGL без тяжёлого 3D-фреймворка;
- mediump shaders;
- ограниченный DPR;
- статические GPU buffers;
- мобильный режим с уменьшенной нагрузкой;
- видимая сцена без блокирующего preload.
