ГРАНЬ v16 — Remote PBR 3D

Открывать через GitHub Pages или другой HTTPS/static hosting.
3D-модели НЕ находятся в архиве: при запуске браузер загружает их из интернета.
Используются самодостаточные GLB-файлы с сохранёнными материалами/текстурами.

Важное:
- index.html — единственный файл сайта.
- Нет Poly Haven API в браузере.
- Нет Base64-моделей.
- GLTFLoader подключается как современный Three.js addon.
- Если внешний GLB временно недоступен, сцена не превращается в чёрный экран.
